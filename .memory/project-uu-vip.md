- **事实**（11-19 用户截图的官方权益页）：免费版 1080p 30 帧；VIP（238 元/年）含「多屏控多屏、无线副屏、虚拟屏、超级屏」。2026-12-01 起生效
- **对外立场**（主人定，三版才定稿，见 [[feedback-doc-writing]]）：「若你恰为 UU远程 VIP 用户，欢迎一试」+ 独立社区项目、与 UU远程 无商业关联、不必为 Snug 专门开通。主次别颠倒，别写得像托。README 顶部 IMPORTANT 框、致谢「三年免费 / 支持商业化（作者已开通 VIP）」、2.7.0 GitHub Release 页均已按此改；应用内更新日志与 v2.7.0 标签说明仍是旧说法「面向已开通 VIP 的用户」，主人没要求改
- **免费版行为不实测**（11-18 主人定）：主人已开通 VIP，不做免费账号实测，也不再提醒。免费版能否切到非主屏、常驻主屏是否照样直接进，均未验证；对外不写，也不包装成绕开 VIP 的办法
- **横向扩展**：主人赞成支持其他远控（#35 问 RustDesk），已回复「在评估」。Snug 绑 UU 的四处（连接察觉、推流屏判断、手势只接管 UURemoteServer、控制端识别）抽成接口——有了真实的第二个用例才抽象
- **决定：专注 UU，暂不接其他远控**（11-19 主人定）：RustDesk 实测第一步就卡住——官方公共服务器（纽约，本机测得延迟约 800–930ms，本机网络为对称型 NAT）要求控制端先登录账号，局域网直连在主人的大网段 Wi-Fi 下连不进来（Mac 端口在听、防火墙关，连接请求没到，疑为 Wi-Fi 设备隔离，未验证），国内还有墙。ToDesk、向日葵的虚拟屏/多屏同样只在付费档（官网：ToDesk 专业版 158 元/年起、向日葵瓜子会员 158 元/年起；两家免费版都没有虚拟屏），换过去省不了钱。#35、#33 已回复（11-19）：婉拒，并承诺把对接 UU 的四处抽成独立适配层、给社区留口子（主人：「就算咱们不做，也要留个口子给别人做」），#35 留着跟踪，完成后在那里更新。适配层 11-19 已在 remote-adapter 分支抽出（方案按推荐拍板，审过一轮），待真机验证、未合并。RustDesk 测试装的 App、配置、日志已删，系统设置里录屏/辅助功能列表可能残留一项 RustDesk
- **RustDesk 源码结论**（11-19 读 1.5.3，dcb6291；未实测）：连入时起 `RustDesk --cm` 连接管理窗口（显示控制端名字），登录信息带控制端名字/平台/ID；连上默认推主屏，但手机端菜单有「跟随远程指针」（Mac 多于一块屏才出现），开着就推指针所在的屏，中途加的屏会同步到控制端列表；输入由 `RustDesk --server` 以 CGEventPost(HID) 注入，每个事件带 eventSourceUserData=100；手机触控模式：点=左键、单指滑=左键拖、长按=右键、双指只缩放本地画面、三指上下=按行滚轮；抓屏用 CGDisplayStream（macOS 14 起弃用），Mac 上有 VideoToolbox 硬编。待实测：新系统上抓屏是否正常/是否每月弹录屏授权、国内经公共服务器的延迟画质、跟随指针切到 Snug 屏

**Why:** UU 收费改变了 Snug 的用户前提，措辞稍有偏差就像替 UU 推广。
**How to apply:** 提到 UU 收费一律照上面的立场写；RustDesk 评估在主人点头后再起。
